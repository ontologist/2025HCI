WEEK 5 PROMPT: PERSONA STORYBOARD | 第5週プロンプト：ペルソナ・ストーリーボード

Files | ファイル
- 01-storyboard-prompt.txt — the storyboard prompt. Students paste it, then their 2 or 3 personas (Week 4 persona plus 1–2 new ones, same interface), in one message → one storyboard per persona, one per reply: persona illustration, 6-panel script and illustration, storyboard check
- week05-submission-template.txt — Part A (File 1: one storyboard per persona, up to 2 pages each) and Part B (File 2: AI transparency log)
- week05-assignment-LMS.txt — text to paste into the LMS assignment (2 files, 10-point rubric, checklist)

Students download the prompt and template from the Week 5 assignment page:
https://2025hci.tijerino.ai/week05-assignment.html
(Copies are in docs/week05-prompts/. If you edit a file here, copy it there too.)

Flow | 流れ
Week 4 persona + 1–2 new personas → storyboard prompt → for each persona: illustration + 6-panel storyboard + check (type "next" between personas)
→ student checks, corrects, and rewrites in their own words → File 1 (storyboard) + File 2 (AI log)

Best in an AI tool that can make images (ChatGPT, Gemini, Copilot). In Claude, the prompt falls back to simple SVG illustrations.
